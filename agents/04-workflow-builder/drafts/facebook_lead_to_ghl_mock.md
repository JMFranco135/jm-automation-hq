# Mock Workflow: Facebook Lead Form → GHL Tag + Internal Notification

## Goal
Capture Facebook Lead Ads into GoHighLevel, tag as new lead, and notify internal team via message draft.

## Trigger
Facebook Lead Form submission

## Step-by-Step Actions with Conditions

1. **Facebook Lead Ads → Webhook**
   - Trigger: New lead submitted via Facebook Form
   - Action: Send lead data to webhook URL (Zapier/n8n/Make)
   - Required fields: first_name, last_name, email, phone, form_id, page_id

2. **Parse & Validate**
   - Condition: If email is empty → skip to error tag
   - Condition: If email already exists in GHL → skip duplicate
   - Action: Normalize phone to E.164 format

3. **Create/Update Contact in GHL**
   - Action: Search contact by email
   - If not found: Create new contact
   - If found: Update existing contact

4. **Apply Tags**
   - Tag: `new lead`
   - Tag: `facebook lead`
   - Tag: `lead source: facebook ads`
   - Optional: Tag by form name if provided

5. **Set Custom Fields**
   - `Lead Source` = Facebook
   - `Form ID` = {{form_id}}
   - `Lead Date` = {{timestamp}}

6. **Internal Notification Draft**
   - Draft message for Slack/Email to client team

## Required Fields and Tags
Fields: first_name, last_name, email, phone, form_id, page_id, timestamp
Tags: new lead, facebook lead, lead source: facebook ads

## Naming Convention
Workflow name: `FB Lead Form → GHL New Lead + Notify`
Zapier path: `facebook-lead-ghl-tag-notify`
GHL pipeline: `Leads` → Stage: `New`
